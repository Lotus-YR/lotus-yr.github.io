初始化博客

  • 创建博客文件夹

本地运行Hexo

hexo s

更换主题

  1. 下载主题icarus,解压到themes目录
  2. 修改_config.yml中主题配置
  3. 修改_config.icarus.yml中主题配置
  4. 本地启动

编写博客

  1. 创建博客 `hexo new post 博客名称
  2. 编辑博客内容

发布

  1. 安装Hexo部署插件
    npm install hexo-deployer-git --save
  2. 修改_config.yml配置
  3. 生成并部署
    hexo g -d
